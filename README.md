# Global-Food-Production-Trends-Using-Power-BI-Project
End-to-end Power BI analytics solution for global food production (1961-2021). Uses Power Query for ETL and data modeling, and DAX for measures and aggregations, delivering an interactive dashboard with KPI cards, geospatial maps, time-series and crop-share visuals across 226 countries and 22 crops for data-driven agricultural insights.
